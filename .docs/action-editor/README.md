# 动作编辑器入门

这份教程用于第一次制作一个可预览、可保存并能绑定到角色的动作图。动作图保存为 `.motion.json`，运行时按 60 Hz 采样。

## 目标

完成下面的流程后，你会得到一个动作图，并能在编辑器预览或将它写入角色定义：

1. 选择一个现有目标骨架。
2. 新建动作图，或从原版 Motion 导入一个片段。
3. 在时间轴上编辑根姿态和部件轨道。
4. 在状态图中把片段接到入口状态，并按需要添加转换。
5. 预览时间轴、事件和运动效果。
6. 保存动作图，再显式绑定到角色。

## 先决条件

- 已能启动游戏并打开 Mod/动作编辑器。
- 目标角色使用现有 `Nana`、`Ryoko` 或 `Yuki` 骨架之一。本教程覆盖这三种现有骨架；非玩家入口目前使用临时合成预览链，尚未提供真实目标骨架与已有动作槽的完整绑定流程。
- 若要绑定到角色，先准备一个可写入的 `.character.json` 文件；其 `BasePreset` 必须与动作图的 `Skeleton` 相同。
- 导入原版 Motion 时，原版资源必须已经被游戏加载。导入只读取资源，不修改原文件。
- 若要试用非玩家预览，目标实体资源必须已加载；编辑器会为预览创建临时的 `Process/parent` 链。运行时绑定目标仍需有可解析的同类骨架。

## 步骤

### 1. 选择目标并打开编辑器

在动作编辑器打开“骨架与动作图”。在窗口顶部选择骨架。新建动作图时会带有一个默认片段和入口状态；图标识需要是非空值。

左侧预览显示当前图的运行结果。点击“重载预览”会按当前动作图重新创建预览世界。方向键移动预览角色，空格跳跃；“单帧”推进一个逻辑步，“播放”连续推进。

要试用非玩家预览，从左侧实体资源列表选择目标并点击“使用实体建立预览骨架”。编辑器会把图的骨架标识设为 `legacy:<实体资源名>`，清空当前片段轨道和 IK 链，然后创建临时合成的 `Process/parent` 链。该预览尚未读取目标实体真实 Create 后的骨架，也未提供已有动作槽的姿态替换注册；`EntitySlots` 当前用于节点别名解析，不能完成该动作槽绑定。

### 2. 新建或导入动作

在“时间轴”页选择片段。输入新片段标识后点击“新增片段”，再设置长度（60 Hz 帧）和是否循环。

要复用原版动作，在顶部的原版 Motion 列表选择资源并点击“导入原版”。导入结果仍可按普通轨道编辑。导入后请点击“重载预览”检查姿态和播放长度。

### 3. 加载预览骨架和肢体预设

点击“重载预览”后，编辑器会从隔离预览世界读取当前实例的骨骼节点和父子关系，并在状态栏显示已加载的节点数。缺少参考姿态的片段会自动补上第 0 帧的局部偏移，避免第一次拖动时没有骨长。

在时间轴的骨骼选择旁点击“应用肢体预设”，可为左右手和左右脚建立连续的 `root → mid → end` 两骨链。预设只在动作图还没有 IK 链时填充；已有绑定会保留。选择一个末端节点后点击“绑定所选末端”，编辑器会从预览骨架读取它的两级父节点并建立该链。选择链中的任一节点后点击“解除所选 IK”会移除包含该节点的链。

绑定要求预览中存在连续的两级父节点；根节点不能作为末端。无效选择、缺少父节点或未加载预览时，原因会显示在窗口底部。

### 4. 编辑骨骼轨道

在时间轴选择部件骨骼和动作帧。勾选“姿态根偏移”时编辑的是 `Root` 轨道；否则编辑所选部件轨道。填写局部 X/Y、角度、缩放和贴图帧，点击“写入关键帧”。同一帧再次写入会替换原关键帧。

关键帧按帧号递增保存。位移和缩放线性插值，角度取最短旋转方向，贴图帧在关键帧之间保持上一帧。根偏移只改变姿态，不改变实体在世界中的位置。

预览画布支持直接拖动节点。左键按住骨骼或根节点并移动，松开时才写入当前帧；按 Esc 或右键可取消，取消不会修改文档。拖动根节点会写入根轨道；拖动未绑定节点会在保持当前偏移长度的情况下旋转该关节。拖动 IK 末端时固定链根并保持两段当前长度，沿拖动开始时的弯曲方向求解；目标超出链长会夹到可达范围，零长度或根目标重合会显示原因。一次拖动只产生一条撤销记录。

节点拖动、镜像和 IK 尚未完成窗口验收，目前存在拾取坐标偏差、IK 局部坐标回放及编辑后预览刷新问题。修改后请点击“重载预览”和“预览当前帧”确认结果；需要精确调整时，使用时间轴中的数值编辑。

### 5. 设置状态和事件

在“状态图”页新增状态节点，选择它后编辑节点 JSON。状态引用一个片段，并可配置固定速度、左右输入、重力、跳跃和显式位移。把入口设为当前状态；节点之间可在图中连线，再在节点 JSON 中补充转换条件。

在“事件配置”页读取或写入片段事件。事件可以指定帧或接触区间，并选择伤害、互动、生成、销毁、SDK 事件或地图事件。图参数页保存状态转换所用的数值参数。

### 6. 预览并保存

点击“预览当前帧”检查所选帧的姿态；点击“重载预览”检查状态机、运动、碰撞和事件。出现错误时，先看窗口底部状态文字，再修正无效帧、骨骼名称、片段引用或状态转换。

点击“保存”写入当前文件；首次保存会打开动作图文件选择器。也可以使用“另存为”保存新文件，“加载”打开已有 `.motion.json`。保存前会验证图版本、骨架、片段、轨道、关键帧和状态引用。

### 7. 绑定到角色

保存动作图后点击“将动作图保存到角色”，选择目标 `.character.json`。编辑器会检查角色骨架与动作图骨架一致，然后写入图标识。角色文件仍保留原有动作槽配置；未设置动作图的角色继续使用原动作。

“应用到游戏角色”只建立当前会话的运行时覆盖，适合快速试用。需要让角色在下次加载时继续使用动作图时，必须完成上面的显式绑定并把动作图放在内容扫描或 Mod 的 `content.motions` 中。

## 预期结果

- 预览中的姿态随时间轴和状态转换变化，实体移动仍由状态的运动设置驱动。
- 保存后重新加载，关键帧、事件、状态和参数保持一致。
- 绑定成功后，角色定义引用该动作图；骨架不匹配时保存会被拒绝并显示原因。
- 关闭运行时覆盖或卸载拥有该资源的 Mod 后，角色恢复原来的动作配置。

## 验证

按下面顺序做一次最小验证：

1. 新建一个 60 帧循环片段，在 `HEAD` 轨道写入第 0 帧和第 30 帧的不同角度。
2. 点击“重载预览”，在骨骼选择中确认节点已从预览实例加载；需要时点击“应用肢体预设”。
3. 在预览画布拖动一个节点，松开后点击“撤销”，确认一次撤销即可恢复；再次拖动后按 Esc，确认文档没有新增修改。
4. 点击“重载预览”和“预览当前帧”，确认中间帧出现平滑旋转。
5. 保存后关闭并重新加载文件，确认轨道、IK 链和关键帧列表仍在。
6. 将动作图绑定到同骨架角色，重新打开角色预览，确认角色使用入口状态。
7. 在状态图中加入一个可触发转换的条件，按对应输入运行预览，确认最多每个逻辑步转换一次。

## 常见问题

**为什么无法保存？** 先检查动作图标识是否为空、片段长度是否大于零、关键帧是否按帧号递增、轨道名称是否属于所选骨架，以及状态是否引用现有片段。

**为什么绑定角色失败？** `BasePreset` 和动作图 `Skeleton` 必须完全一致；同时确认角色文件可写且动作图已经保存。

**拖动节点后姿态方向反了怎么办？** 当前拖动与 IK 回放仍有坐标问题。请使用时间轴中的局部 X/Y 和角度调整，再重载预览确认。

**为什么 IK 按钮没有生效？** “绑定所选末端”需要已加载预览，并且所选末端必须有连续的两级父节点。若动作图已有 IK 链，“应用肢体预设”不会覆盖它；请先解除所选链，再绑定目标末端。

**拖动时如何放弃本次操作？** 在画布上按 Esc 或右键。只有鼠标左键松开才会写入关键帧，取消不会产生撤销记录。

**为什么拖动提示链段长度为零？** 该节点没有可用的参考局部偏移。先点击“重载预览”生成参考姿态，或在时间轴为节点写入非零 X/Y 偏移，再重新拖动。

**导入后姿态和原版不同怎么办？** 导入按原版 30 Hz 数据换算为 60 Hz，并保留原部件顺序和缩放。检查是否选错骨架或遗漏了原版资源依赖，再重载预览。

**预览移动了，但姿态根轨道没有移动实体，是否正常？** 正常。`Root` 只负责骨架姿态；需要实体移动时，请在状态的运动设置中填写速度、重力、跳跃或显式位移。

**关闭编辑器后动作消失怎么办？** “应用到游戏角色”是当前会话覆盖。要持久化，请先保存动作图，再使用“将动作图保存到角色”，并确保动作图已随内容或 Mod 注册。
